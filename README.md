# utez-2c-inventario-javafx-equipo13
Descripción del sistema:
Es un programa para que una tienda pueda gestionar su inventario. El codigo permite registrar, editar, consultar, y eliminar productos de manera local, ya que la información se guarda en un archivo físico.

Como ejecutar el programa:
Tienes que abrir el proyecto que se importa la carpeta eIntelliJ IDEA.
Para ejecutarlo tiene que localizar la clase que se llama HelloApplication y darle click en run (triangulo verde).
Su uso es que saldra la pantalla principal y cargaran los datos existentes en el archivo.

Explicación del programa:
Todos los datos que ingrese el usuario se guardan en data/productos.csv los cuales son separados con comas, también cualquier cambio que haga el usuario el archivo se actualiza en automatico.
Las funciones principales:
Hay control total sobre los productos.
La busqueda es en tiempo real (se puede tanto por nombre como por codigo del producto).
Se puede ordenar la tabla tanto por codigo, nombre, precio y stock.
Hay control de errores en caso de que el usuario deje campos vacios o escriba datos incorrectos.
